# -New-York-City-Airbnb-Open-Data-Linear-Regression-
The **New York City Airbnb Open Data** dataset by AB NYC contains information about Airbnb listings, including prices, room types, locations, and reviews. We used this dataset to analyse rental prices and predict listing prices using **Linear Regression**.
## **Dataset Description – New York City Airbnb Open Data**

The **New York City Airbnb Open Data** dataset by AB NYC contains information about Airbnb listings available across different neighbourhoods of New York City. It provides details about rental properties, room types, prices, availability, number of reviews, minimum nights, and host information.

This dataset is used to analyse the factors that influence Airbnb rental prices in New York City. It includes both numerical and categorical features that help us understand pricing patterns and rental trends.

For our project, we have used this dataset to perform **Linear Regression**, a supervised machine learning technique, to predict Airbnb listing prices based on relevant features. The dataset is preprocessed by handling missing values, removing unnecessary columns, and encoding categorical variables before applying the regression model.
